## :dart: O guia para alavancar a sua carreira

> Pessoa desenvolvedora **full-stack** é quem transita pelas duas pontas de uma aplicação web: o **front-end** (o que roda no navegador — HTML, CSS, JavaScript e frameworks como React) e o **back-end** (o que roda no servidor — APIs, bancos de dados, autenticação, deploy). Não significa saber tudo com a mesma profundidade: significa conseguir **entregar uma funcionalidade inteira**, da tela ao banco, e conversar bem com especialistas de cada lado. É o perfil mais pedido em startups, pequenas empresas e times enxutos — e, no Brasil, uma das portas de entrada mais comuns na programação.
>
> Este guia é para quem está começando do zero ou já sabe um dos lados e quer fechar o ciclo. Ele organiza roadmap, trilha de entrada, cursos, documentação, ferramentas, projetos, certificações, salários e comunidades, priorizando conteúdo em português e gratuito. Todo link foi verificado na data da última revisão. Para aprofundar cada lado da pilha, use também os guias irmãos de [Front-end](https://github.com/arthurspk/guiadofrontend), [Back-end](https://github.com/arthurspk/guiadobackend) e [TypeScript](https://github.com/arthurspk/guiadetypescript).

## 💡 Nossa proposta

> A proposta deste guia é dar uma ideia sobre o atual panorama e guiá-lo se você estiver confuso sobre qual será o seu próximo aprendizado, sem influenciar você a seguir os 'hypes' e 'trends' do momento. Acreditamos que com um maior conhecimento das diferentes estruturas e soluções disponíveis poderá escolher a ferramenta que melhor se aplica às suas demandas. E lembre-se, 'hypes' e 'trends' nem sempre são as melhores opções.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Como a web funciona** — navegador, servidor, HTTP, DNS, o que é uma API. Sem isso, o resto vira decoreba.
2. **Front-end básico** — HTML semântico, CSS (flexbox, grid, responsividade) e JavaScript moderno (DOM, eventos, `fetch`, `async/await`).
3. **Ferramentas do ofício** — terminal, Git e GitHub, VS Code, npm. Publique tudo o que fizer.
4. **Front-end com framework** — React (ou Vue), componentes, estado, rotas e consumo de API. TypeScript entra aqui.
5. **Back-end** — Node.js com Express/Fastify (ou Python com Django/FastAPI, Java com Spring, PHP com Laravel): rotas, REST, validação, autenticação (JWT/sessões), variáveis de ambiente.
6. **Banco de dados** — SQL com PostgreSQL (modelagem, JOIN, índices), um ORM (Prisma/Drizzle) e noções de NoSQL (MongoDB, Redis).
7. **Qualidade e entrega** — testes (Vitest/Jest, Playwright), Docker, CI com GitHub Actions e deploy (Vercel, Render, Railway, Fly.io).
8. **Full-stack de verdade** — um framework que une as pontas (Next.js), segurança (OWASP Top 10), observabilidade, cache e noções de system design.

## 🚀 Por onde começar
1. **Entenda a web antes de programar.** Leia [Como a Web funciona](https://developer.mozilla.org/pt-BR/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works) na MDN e a visão geral de [HTTP](https://developer.mozilla.org/pt-BR/docs/Web/HTTP).
2. **Instale o ambiente:** [Visual Studio Code](https://code.visualstudio.com/), [Git](https://git-scm.com/) e [Node.js](https://nodejs.org/en) (versão LTS). No Windows, use o [WSL](https://learn.microsoft.com/pt-br/windows/wsl/install).
3. **HTML e CSS:** faça o [Curso de HTML5 e CSS3 do Curso em Vídeo](https://www.youtube.com/playlist?list=PLHz_AreHm4dkZ9-atkcmcBaMZdmLHft8n) ou o [Design Web Responsivo do freeCodeCamp em português](https://www.freecodecamp.org/portuguese/learn/), e publique a primeira página no GitHub Pages com o [Curso de Git e GitHub](https://www.youtube.com/playlist?list=PLHz_AreHm4dm7ZULPAmadvNhH6vk9oNZA).
4. **JavaScript:** [Curso de JavaScript do Curso em Vídeo](https://www.youtube.com/playlist?list=PLHz_AreHm4dlsK3Nr9GVvXCbpQyHQl1o1) e, para consolidar, o [Discover da Rocketseat](https://app.rocketseat.com.br/journey/discover/overview) ou o [Eloquent JavaScript](https://eloquentjavascript.net/).
5. **Feche o ciclo com um curso full-stack completo e gratuito:** o [Full Stack Open em português](https://fullstackopen.com/ptbr/) (React + Node + banco de dados + testes + deploy) ou o [currículo Certified Full Stack Developer do freeCodeCamp](https://www.freecodecamp.org/learn/full-stack-developer/).
6. **Aprenda SQL** com o [Curso de MySQL do Curso em Vídeo](https://www.youtube.com/playlist?list=PLHz_AreHm4dkBs-795Dsgvau_ekxg8g1r) ou o [SQLBolt](https://sqlbolt.com/) e migre para o [PostgreSQL](https://www.postgresql.org/) no primeiro projeto real.
7. **Construa 3 projetos completos** (front + API + banco + deploy) e publique cada um com README, prints e link no ar. Ideias na seção [Projetos práticos](#-projetos-práticos-e-desafios).
8. **Entre na comunidade e nas vagas:** [TabNews](https://www.tabnews.com.br/), Discord da [Rocketseat](https://www.rocketseat.com.br/) e os repositórios de vagas [frontendbr](https://github.com/frontendbr/vagas) e [backend-br](https://github.com/backend-br/vagas). Mire a primeira vaga júnior quando tiver os 3 projetos.

Seu primeiro full-stack em 1 minuto — uma página que chama uma API, tudo em um arquivo:

```bash
mkdir ola-fullstack && cd ola-fullstack
npm init -y
```

```js
// server.js — front-end + API no mesmo arquivo, sem instalar nada (Node.js 20+)
const { createServer } = require("node:http");

const pagina = `<!doctype html>
<h1>Olá, full-stack!</h1>
<p id="msg">carregando…</p>
<script>
  fetch("/api/ola").then(r => r.json()).then(d => { msg.textContent = d.mensagem; });
</script>`;

createServer((req, res) => {
  if (req.url === "/api/ola") {                       // back-end: rota da API
    res.writeHead(200, { "Content-Type": "application/json" });
    return res.end(JSON.stringify({ mensagem: "Resposta do servidor 👋" }));
  }
  res.writeHead(200, { "Content-Type": "text/html; charset=utf-8" });
  res.end(pagina);                                    // front-end: página HTML
}).listen(3000, () => console.log("http://localhost:3000"));
```

```bash
node server.js     # abra http://localhost:3000 no navegador
```

## 🤖 IA na prática
Full-stack é a área em que assistentes de IA mais mudaram o dia a dia: eles geram CRUDs, componentes e testes em segundos. O risco é igualmente grande — código que "funciona" com falhas de segurança que você não sabe ler. Use IA para **ir mais rápido no que você já entende** e para **aprender o que ainda não entende**, nunca para pular o entendimento.

**Para aprender**
- Cole uma mensagem de erro inteira (ex.: `TypeError: Cannot read properties of undefined (reading 'map')` ou `ECONNREFUSED 127.0.0.1:5432`) com o trecho de código e peça: *"explique a causa provável em ordem de probabilidade e como confirmar cada hipótese"*.
- Peça um **mapa mental de uma requisição**: "o que acontece, passo a passo, quando o usuário clica em 'Entrar' num app React + Node + Postgres?". Depois compare com o que você vê na aba *Network* do DevTools.
- Peça para **revisar seu código como um sênior faria** — nomeação, tratamento de erros, validação de entrada, N+1 em consultas — e reescreva você mesmo.
- Peça **exercícios com gabarito** sobre o tópico da semana (JOINs, `async/await`, hooks do React, JWT) e só olhe a resposta depois de tentar.
- Use o modo de estudo: *"não me dê o código; me faça perguntas até eu chegar na solução"*.

**Para trabalhar**
- No editor, [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Gemini Code Assist](https://codeassist.google/) para autocompletar, gerar testes e explicar código legado. No terminal, [Claude Code](https://code.claude.com/docs/en/overview) para tarefas maiores: "adicione paginação ao endpoint `/produtos`, com testes".
- Para prototipar interfaces, [v0](https://v0.app/) gera React + Tailwind a partir de um prompt; [bolt.new](https://bolt.new/) monta um app inteiro no navegador. Trate o resultado como rascunho: leia, entenda e refatore antes de subir.
- Bons usos diários: escrever a migração SQL a partir da descrição da tabela, gerar dados de teste (*seed*), converter um `curl` em código, escrever o README e a documentação OpenAPI da sua API.
- Depois de **cada** sugestão aceita: rode os testes, o linter e abra a aplicação. Se você não consegue explicar uma linha, não faça commit dela.

**Limites e boas práticas**
- IA **inventa pacotes e APIs** que não existem (e criminosos registram esses nomes no npm — o chamado *slopsquatting*). Confirme no registro do npm e na documentação oficial antes de instalar.
- Segurança não vem de graça: peça explicitamente por validação de entrada, senhas com *hash* (bcrypt/argon2), consultas parametrizadas e proteção contra XSS/CSRF, e confira com o [OWASP Top 10](https://owasp.org/www-project-top-ten/).
- Nunca cole segredos (`.env`, chaves de API, dados de clientes) em ferramentas sem a política da sua empresa.
- "Vibe coding" funciona para protótipo, não para produção nem para entrevista: quem contrata vai perguntar *por quê* o código é assim.

**Full-stack + IA como produto.** Saber colocar um LLM dentro de uma aplicação (chat, busca semântica, automações) virou diferencial em vagas full-stack. Comece por aqui:
- [GitHub Copilot](https://github.com/features/copilot) — Autocomplete e chat com IA no editor; gratuito para estudantes e com plano free.
- [Cursor](https://cursor.com/) — Editor baseado no VS Code com IA integrada ao fluxo de trabalho.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: implementa features, escreve testes e explica código legado.
- [Gemini Code Assist](https://codeassist.google/) — Assistente de código do Google com plano gratuito para uso individual.
- [v0 (Vercel)](https://v0.app/) — Gere interfaces React + Tailwind a partir de um prompt e exporte o código.
- [bolt.new](https://bolt.new/) — Ambiente no navegador que gera e roda apps full-stack com IA.
- [Vercel AI SDK](https://ai-sdk.dev/) — SDK TypeScript para colocar LLMs no seu app: streaming, tools e agentes.
- [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) — Padrão aberto para conectar assistentes de IA às suas APIs, bancos e ferramentas.
- [Ollama](https://ollama.com/) — Rode modelos open source (Llama, Gemma, Qwen) localmente e integre via API.

## 📜 Certificações
Não existe uma certificação oficial de "desenvolvedor full-stack": o mercado brasileiro avalia **portfólio publicado, projetos no ar e domínio prático**. O que pesa no currículo são certificações de **cloud** (onde sua aplicação vai rodar) e certificados de conclusão de cursos reconhecidos — segundo o Guia Salarial 2026 da Robert Half, 48% dos gestores de tecnologia no Brasil pagam mais a quem tem certificações ou conhecimentos especializados.
- [freeCodeCamp — certificações gratuitas](https://www.freecodecamp.org/learn/) — Responsive Web Design, JavaScript, Front End Libraries, Back End e o novo Full Stack Developer: todas gratuitas e verificáveis.
- [Meta Front-End Developer Professional Certificate (Coursera)](https://www.coursera.org/professional-certificates/meta-front-end-developer) — Certificação paga (auditável gratuitamente). Certificado profissional da Meta: HTML, CSS, JavaScript e React.
- [Meta Back-End Developer Professional Certificate (Coursera)](https://www.coursera.org/professional-certificates/meta-back-end-developer) — Certificação paga. Python, Django, APIs e bancos de dados, com projeto final.
- [IBM Full Stack Software Developer Professional Certificate (Coursera)](https://www.coursera.org/professional-certificates/ibm-full-stack-cloud-developer) — Certificação paga. HTML, JavaScript, React, Node, Python, Docker e Kubernetes com foco em cloud.
- [AWS Certified Cloud Practitioner](https://aws.amazon.com/pt/certification/certified-cloud-practitioner/) — Certificação paga. Porta de entrada em cloud; muito pedida em vagas full-stack que fazem deploy na AWS.
- [AWS Certified Developer – Associate](https://aws.amazon.com/pt/certification/certified-developer-associate/) — Certificação paga, para quem desenvolve e faz deploy de aplicações na AWS.
- [Microsoft Certified: Azure Developer Associate (AZ-204)](https://learn.microsoft.com/pt-br/credentials/certifications/azure-developer/) — Certificação paga. Desenvolvimento de soluções na Azure; comum em empresas do ecossistema .NET.
- [Google Associate Cloud Engineer](https://cloud.google.com/learn/certification/cloud-engineer) — Certificação paga, de entrada do Google Cloud para deploy e operação de aplicações.
- [CKAD — Certified Kubernetes Application Developer](https://www.cncf.io/training/certification/ckad/) — Certificação paga, para quem já usa containers e quer comprovar deploy em Kubernetes.
- [Certificados gratuitos da DIO](https://www.dio.me/) — Bootcamps com empresas e certificados de conclusão gratuitos.
- [Certificados da Escola Virtual Bradesco](https://www.ev.org.br/) — Certificados gratuitos e reconhecidos em cursos de programação e web.

## 💼 Carreira e vagas
**Quanto ganha:** o [Guia Salarial 2026 da Robert Half](https://www.roberthalf.com/br/pt/insights/guia-salarial/tecnologia) situa a pessoa desenvolvedora full-stack **júnior entre R$ 6.050 e R$ 8.750**, **pleno entre R$ 9.550 e R$ 15.900** e **sênior entre R$ 12.450 e R$ 20.950** por mês (CLT). A [Pesquisa Salarial do Código Fonte TV 2025](https://pesquisa.codigofonte.com.br/2025) (12,5 mil respostas) registrou média geral de **R$ 8.886 (CLT)** e **R$ 13.344 (PJ)**, com remoto ainda majoritário. Vagas internacionais remotas pagam em dólar, mas exigem inglês fluente.

**O que as vagas pedem:** JavaScript/TypeScript, React (ou Angular/Vue), Node.js (ou Java/Spring, Python, PHP/Laravel, C#/.NET), SQL, Git, APIs REST, testes e noções de Docker/cloud. Dica: nos repositórios de vagas do GitHub abaixo, pesquise por "full stack" e "júnior" nas issues abertas.
- [Pesquisa Salarial de Programadores 2026 (Código Fonte TV)](https://pesquisa.codigofonte.com.br/2026) — A maior pesquisa salarial de devs do Brasil, com filtros por área (full-stack), senioridade, CLT/PJ e região.

- [Guia Salarial 2026 — Tecnologia (Robert Half)](https://www.roberthalf.com/br/pt/insights/guia-salarial/tecnologia) — Faixas salariais por cargo e senioridade; Full-Stack júnior de R$ 6.050 a R$ 8.750, pleno de R$ 9.550 a R$ 15.900.
